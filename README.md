# Typesharp
This is a website which is specifically for people who wants a good control on typing.

TypeSharp is a web-based typing practice platform built specifically for SSC and 
government exam aspirants who need to pass typing/DEST skill tests (SSC CGL, CHSL, 
and similar). Unlike generic typing tools, TypeSharp mirrors the actual exam 
interface and scoring rules, so practice translates directly to exam performance.

## Why TypeSharp
Most typing tools are built for general practice, not for the specific pass/fail 
rules of government typing tests. TypeSharp gives aspirants an accurate, exam-like 
environment with saved progress and tracked improvement over time.

## Features
- Exam-accurate typing tests (WPM, accuracy, error scoring matched to SSC rules)
- User accounts with saved progress and performance history
